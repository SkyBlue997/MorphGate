## Redistribution scope

The initial Phase 1 prerelease is a source release. It does not ship prebuilt
Rust or Go executables or a vendored dependency tree. This file records source
provenance; it is not a complete license bundle for a compiled distribution.

Anyone distributing compiled executables, bundled third-party code, or container
images must review the actual target, features, resolved dependencies, and
toolchain used to build those artifacts, and include the applicable copyright
notices, license texts, and upstream `NOTICE` files. Relevant examples include
the native BoringSSL/AWS-LC license files, Moka's `NOTICE`, Go YAML's `LICENSE`
and `NOTICE`, and the license for any bundled certificate-root data. Shipping
this file alone does not fulfill those obligations.

The committed MaxMind DB test fixtures are synthetic data generated by
[intel/testdata/mmdb-gen](intel/testdata/mmdb-gen/README.md). Production GeoLite2
databases and externally downloaded intelligence feeds are not included in the
source release; their respective terms apply when obtained separately.
