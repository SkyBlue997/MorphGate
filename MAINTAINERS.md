# Maintainers

## Security maintainer

| Maintainer | Project role | Responsibilities |
|---|---|---|
| [@SkyBlue997](https://github.com/SkyBlue997) | Repository owner and security maintainer | Private vulnerability triage; security fixes and dependency updates; review of security-sensitive changes; security advisories and release guidance |

MorphGate is currently maintained by a single owner. The named maintainer is also responsible for the architecture, implementation, documentation and release process. The [commit history](https://github.com/SkyBlue997/MorphGate/commits/master/) and [merged pull requests](https://github.com/SkyBlue997/MorphGate/pulls?q=is%3Apr+is%3Amerged) provide public development records.

Report vulnerabilities through the private channel in [SECURITY.md](SECURITY.md). Use repository issues for non-sensitive bug reports and documentation feedback.

## Project scope and license

MorphGate's supported deployment model is an operator protecting their own web properties, with allowlisted validation traffic. The project's own code is available under [Apache-2.0](LICENSE); dependencies and third-party material retain their own licenses as described in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). The deployment model describes the project's engineering and support scope and does not add restrictions to Apache-2.0.
